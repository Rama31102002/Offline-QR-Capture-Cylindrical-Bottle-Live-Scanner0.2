Device Snapshot Backup (Reinstall Recovery)

Creates one encrypted file with every local user, this device's settings, and the administrator recovery verifier/state — everything a fresh install needs to restore the same local logins and device identity if it's ever uninstalled, reset, or replaced. It does not include captured record photos; use the exports above/below for those. Take a fresh snapshot any time users or settings change.

Multi-Device User Provisioning

Export the local user list as an encrypted package and import it on another authorized tablet. Device registration remains unique on each tablet.

Local Data

Exports create a batch ID but do not permanently mark records as delivered. Records remain re-exportable. Each ZIP is limited to 100 records and approximately 120 MB of source images. Pseudo-deleted records are excluded.
